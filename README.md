# Endereços Brasil 🇧🇷

Serviço de busca de endereços com base aberta para uso público.

Desenvolvido e mantido pelo estúdio digital [Emana](https://emana.digital), utilizado diariamente em nossa plataforma interna de e-commerce.

- 🔍 Pesquise localizações do Brasil utilizando nosso [portal](https://enderecosbrasil.emana.digital) _(útil para conferir os dados da base)_
- 📃 Baixe nossa base de dados de forma simples ao criar uma conta
- 🫴 Contribua para melhorar a qualidade dos nossos dados
- 🍃 Utilize a API comunitária gratuitamente (servidores limitados com recursos compartilhados entre [alguns projetos](https://enderecosbrasil.emana.digital/projetos-que-utilizam) que confiaram no nosso trabalho)

💵 API premium disponível (desempenho garantido). [Entre em contato](https://enderecosbrasil.emana.digital/contato).

---

A principal função do Endereços Brasil é disponibilizar uma API simplificada com a maior quantidade de dados possível. Consumimos dados públicos da internet para gerar o máximo de informações sobre localizações.

A base é atualizada semanalmente com informações de outras bases públicas. Informações verificadas são atualizadas em tempo real. Usuários da plataforma podem sugerir edições abertamente.

Edições são aplicadas automaticamente nas buscas feitas pelo usuário. Antes que as mudanças propaguem para todos, nós **verificamos manualmente a qualidade dos dados**, isso não garante a veracidade das informações, mas garante uma saída normalizada.
